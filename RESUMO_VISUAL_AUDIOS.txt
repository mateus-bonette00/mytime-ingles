4. ENDPOINTS DA API
================================================================================

   PROGRESS ROUTES (Requer Autenticação)
   ────────────────────────────────────

   GET /api/progress
   └─ Retorna: { stats, progress }

   GET /api/progress/phrases
   └─ Retorna: { phrases: [...] } com todos os audio_url

   GET /api/progress/phrases/:phraseNumber  <── USADO PELO LESSONPAGE
   └─ Retorna: { phrase: { audio_url, ... } }

   POST /api/progress/phrases/:phraseNumber/complete
   └─ Marca frase como concluída

   POST /api/progress/phrases/:phraseNumber/incomplete
   └─ Marca frase como não concluída


   ADMIN ROUTES (Requer Autenticação + Admin)
   ──────────────────────────────────────────

   POST /api/admin/phrases
   └─ Recebe: { phrase_number, text_en, text_pt, audio_url, ... }

   PUT /api/admin/phrases/:phraseNumber
   └─ Atualiza: audio_url, text_en, text_pt, category, ...

   DELETE /api/admin/phrases/:phraseNumber
   └─ Remove frase e referência de áudio

   POST /api/admin/phrases/bulk
   └─ Importa múltiplas frases com audio_url em lote

7. PROBLEMAS CRÍTICOS
================================================================================

   [!] PROBLEMA 1: Incompatibilidade de Formato
   ─────────────────────────────────────────────
   Schema referencia:  "/audios/phrase_01.mp3"
   Arquivos reais:    "/audios/1.m4a.mp4"
   Impacto:           CRÍTICO - Seed data não funciona
   Solução:           Atualizar schema.sql linhas 179-190


   [!] PROBLEMA 2: Nomes Inconsistentes
   ─────────────────────────────────────
   Arquivos com espaço: "14 b.m4a.mp4", "15 b.m4a.mp4", "17 b.m4a.mp4"
   Padrão esperado:     "14b.m4a.mp4", "15b.m4a.mp4", "17b.m4a.mp4"
   Impacto:             MÉDIO - Erro potencial ao referenciar
   Solução:             Renomear 3 arquivos


   [!] PROBLEMA 3: Significado Obscuro das Variações "b"
   ──────────────────────────────────────────────────────
   Pergunta:  Por que 25 áudios "b"?
   Hipótese:  - Diferentes locutores (nativo vs aluno)?
              - Diferentes velocidades (rápido vs lento)?
   Impacto:   BAIXO - Falta de documentação
   Solução:   Documentar propósito das variações


   [!] PROBLEMA 4: Falta de Validação
   ──────────────────────────────────
   Situação:  Não há validação se arquivo existe
   Risco:     URLs inválidas podem ser salvas no BD
   Impacto:   MÉDIO - Erros em produção
   Solução:   Implementar validação de audio_url
